HydrationReminder

A mobile app built for Mobile Application Development - Practical Tutorial 06.

 What We Built
- Local Notifications: Uses expo-notifications to request permissions and schedule repeating hydration alerts at custom intervals without an external server.
- Tab Navigation: Built with expo-router featuring 3 tabs:
  - Reminder: Set custom messages, adjust reminder intervals, and start/stop alerts.
  - Tips: Static information on the health benefits of drinking water.
  - About: App information and developer details.
- Foreground Notifications: Configured to display alerts even while using the app.
